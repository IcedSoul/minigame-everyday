# 快乐拼拼豆 · Day 06

微信小游戏 / 浏览器双端运行的像素拼豆游戏。

## 游戏玩法

1. **取豆**：点击图案区域中的豆，自动选中该豆所在的连通同色区域，全部取出到暂存槽
2. **放豆**：点击图案区域中的空位，自动从暂存槽取第一个颜色匹配的豆放入
3. **批量放置**：点击"放置豆"按钮，自动将暂存槽中所有可匹配的豆放入对应空位
4. **胜利条件**：所有豆槽都被对应颜色的豆填满

## 技术栈

- **引擎**：Canvas 2D 原生（无第三方引擎）
- **动画**：自写轻量 Tween 引擎
- **平台**：微信小游戏 + 浏览器
- **包体**：< 30KB JS

## 本地调试

```bash
node serve.js
# 打开 http://localhost:8060
```

## 项目结构

```
js/
├── main.js              # 主入口（双端兼容）
├── core/
│   ├── config.js        # 游戏配置常量 + 图案 mask
│   ├── GameState.js     # 核心状态模型
│   ├── BoardLogic.js    # 连通区域检测（BFS）
│   └── ColorDistributor.js  # 颜色分布与打乱算法
├── render/
│   └── Renderer.js      # Canvas 2D 渲染器
├── anim/
│   ├── Tween.js         # Tween 缓动引擎
│   └── AnimManager.js   # 动画管理器
└── input/
    └── TouchHandler.js  # 触摸/点击事件
```

## 核心算法

- **连通区域检测**：BFS Flood Fill
- **颜色分布**：确定性区域分割 + 噪声点缀
- **打乱算法**：Fisher-Yates + 聚集度控制
- **可解性保证**：每种颜色的豆数量 = 目标数量，必定可解
