# 每天复刻一个微信小游戏

> 一个独立开发者的 100 天小游戏复刻计划：每天复刻一款微信/抖音爆款小游戏，产出能跑的代码 + 一篇复盘文章。

作者：xiaofengguo · 开始时间：2026-05-20

---

## 这是什么

**每天复刻一个微信小游戏，连续 100 天。**

复刻不是抄袭，是把核心循环拆出来，用最短的链路重做一遍——这个过程对于理解一款产品为什么"上头"，比读多少篇分析都更直接。

每一天产出：
- ✅ 一份能跑的代码（微信小游戏 + 网页双端）
- ✅ 一篇复盘文章（核心循环拆解 + AI 协作过程 + 踩坑记录）

## 技术栈

- **游戏引擎**：Phaser 3（前期）/ Cocos Creator 3.8（中难度以上）
- **脚手架**：`wbgbg/phaser-wx-template`（Phaser 双端模板）
- **开发工具**：微信开发者工具 + WorkBuddy（AI Agent + `weixin-minigame-helper` 插件）
- **语言**：JavaScript / TypeScript
