## 一、热门小游戏盘点（去同质化后的复刻候选清单）

### 筛选原则
1. **聚焦畅玩榜（IAA 休闲向），不挑畅销榜重度 SLG/MMO**——每日复刻必须 1 天能跑通，重度氪金 SLG（如《无尽冬日》《掌上谈兵》《三国：冰河时代》）排除。
2. **同类玩法只保留代表作**：
   - 「打螺丝 / 拼豆 / 拼图收纳」一类合并
   - 「三消 / 抓大鹅 / 消水果」一类合并
   - 「合成放置（灵画师 / 道友挖宝 / 我的花园世界）」一类合并
3. **复刻难度评估维度**：核心循环逻辑复杂度、美术资源量、物理/算法门槛、存档与社交功能。

## 三、技术栈与工作流建议

### 推荐技术栈
```
游戏引擎：Phaser 3（推荐，前 8 款全部够用）+ Cocos Creator 3.8（中难度以上）
脚手架：  wbgbg/phaser-wx-template（双端）
开发工具：微信开发者工具 + WorkBuddy `weixin-minigame-helper` 自动预览
语言：    TypeScript（强类型，AI 生成质量更高）
仓库：    minigame-everyday 单 repo / 每日一目录（day-01-screw、day-02-fruit ...）
```

### 每日工作流
```
1. 选题（看清单）→ 2. 拆核心循环（30 分钟）→ 3. AI 拉脚手架（10 分钟）
→ 4. 实现核心玩法（2-4 小时）→ 5. weixin-minigame-helper 预览迭代
→ 6. 录 GIF + 写文章（1 小时）→ 7. 推 GitHub + 文章发布
```

### 文章配套
- 每日产出：**`/day-XX-{name}/`** 目录 + **`/articles/day-XX.md`** 复盘文 + 1 段 GIF
- 系列收官：编 PPT + 总结复刻一百天的 Top 10 难点（用内置 `pptx` Skill）
